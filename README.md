<h1>Telegram UWP</h1>
</div>

**Telegram UWP** is an alternative Telegram client built for **Windows 10 Mobile**, designed to recreate the look, feel, and functionality of the official Telegram applications.

The project aims to provide a native Windows experience using the **Universal Windows Platform (UWP)**, with an interface inspired by Microsoft's design language and the official Telegram clients of the Windows Phone era.

Telegram UWP is intended for enthusiasts of Windows Phone, Windows 10 Mobile, and UWP applications, as well as anyone interested in keeping these platforms usable and alive.
